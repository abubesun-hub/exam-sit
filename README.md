# نظام خارطة جلوس الطلبة (واجهة عربية RTL)

حلّ خفيف يعمل بدون اتصال لتوليد خرائط جلوس القاعات والقطاعات مع حفظ محلي عبر localStorage وتصميم نيومورفيك مريح.

## المزايا
- واجهة عربية RTL بالكامل مع أيقونات Bootstrap Icons.
- تصميم نيومورفيك عصري مع دعم السمة الفاتحة/الداكنة.
- يعمل محلياً دون سيرفر ويخزن البيانات في المتصفح.
- إدارة الطلاب (إضافة/بحث/حذف).
- إنشاء قاعات، إضافة قطاعات، تحديد عدد الصفوف ومقاعد كل صف.
- توليد المقاعد وعرض شبكة الجلوس وتوزيع تلقائي للطلاب.
- استيراد CSV/JSON محلياً، ودعم Excel عبر SheetJS (يتطلب اتصالاً أول مرة).
- نسخ احتياطي تلقائي ومحفوظات للرجوع.
- طباعة نظيفة جاهزة للتحويل إلى PDF.

## التشغيل السريع
1. افتح الملف `index.html` مباشرة في المتصفح (Chrome/Edge).
2. من تبويب "الطلاب" أضف الطلبة أو استوردهم من CSV/JSON.
3. من تبويب "القاعات والقطاعات" أنشئ قاعة، أضف قطاعاً، حدّد عدد الصفوف واكتب مقاعد كل صف مثل: `8,8,7`.
4. اضغط "توليد المقاعد" ثم "توزيع تلقائي" لملء المقاعد بالطلاب.
5. من زر "طباعة" اطبع أو احفظ PDF.

### معلومات المدرسة
- من تبويب "لوحة التحكم" ستجد بطاقة "معلومات المدرسة" لإدخال:
  - اسم المدرسة
  - الامتداد (بنين/بنات/مختلطة)
  - العام الدراسي
  - مدير المدرسة
  - رئيس اللجنة الامتحانية
  - شعار المدرسة (اختياري – يتم حفظه محلياً ويظهر معاينة صغيرة)
- يتم حفظ هذه المعلومات تلقائياً في الإعدادات المحلية (localStorage).

### استيراد/تصدير وحفظ العمل
- "تصدير نسخة كاملة": يُصدّر كل شيء في حزمة واحدة JSON تشمل البيانات والإعدادات.
- "حفظ الملف باسم...": يتيح اختيار اسم وموقع الحفظ عبر متصفحات تدعم File System Access (Chrome/Edge). في غير ذلك سيبدأ تنزيل تلقائي.
- الاستيراد: استخدم نفس الصفحة لاختيار ملف JSON سابق. يدعم الأنماط:
  - `{ students: [...] }` لإضافة طلاب فقط.
  - هيكل بيانات فقط `{ students, halls, assignments }`.
  - الحزمة الكاملة `{ data: {...}, settings: {...} }` (موصى به).

## تنسيقات الاستيراد
- CSV: أول ثلاثة أعمدة بالترتيب `الاسم,المرحلة,الشعبة` (مع ترويسة اختيارية).
- JSON: إمّا `{ students: [...] }` لإضافة طلاب فقط، أو هيكل كامل للبيانات مطابق للتصدير.
- Excel: ملف `.xlsx/.xls` (يتطلب تحميل مكتبة SheetJS من الإنترنت عند أول استخدام).

## النسخ الاحتياطي
يُنشئ التطبيق نسخة عند الحفظ؛ يمكن تغيير الحدّ من تبويب "الإعدادات". لاستعادة نسخة قديمة، افتح أدوات المطور واقرأ `StorageAPI.getBackups()` أو عدّل الكود وفق الحاجة.

## ملاحظات التصميم
- تم اختيار تباينات ألوان مريحة و"ظلال ناعمة" (Neumorphism) مع مراعاة قابلية القراءة.
- الشبكة مرنة: يمكنك تحديد 2 أو 3 أو 4 صفوف بسهولة عبر إدخال المقاعد.
- الطباعة تستخدم نمطاً مبسّطاً وحدوداً واضحة.

## خريطة البيانات
```
{
  students: [{ id, name, stage, className }],
  halls: [{ id, name, sectors: [{ id, name, rows: [{ seats }] }] }],
  assignments: { "hallId:sectorId:row:seat": studentId }
}
```

## حدود أولية / أفكار تطوير لاحقة
- سحب وإفلات لتبديل المقاعد يدوياً.
- مولد قوالب سريعة (2/3/4 خطوط) بزر واحد.
- منع الجلوس بجوار زملاء نفس الشعبة (قواعد توزيع).
- أكثر من طريقة طباعة: لكل قطاع/لكل قاعة.
